# 🐍 Snake Game

A classic Snake Game built using HTML, CSS, and JavaScript.  
Control the snake, eat the food, and grow longer — avoid hitting the walls or yourself.

🔗 **Live Demo:**  
https://shinzoooo.github.io/Snake_game/

---

## 📖 Description

This is a browser-based Snake Game inspired by the classic Nokia snake game.  
The player controls the snake using keyboard arrow keys. Each time the snake eats food, it grows longer and the score increases. The game ends when the snake collides with the wall or itself.

---

## 🎮 Features

- Classic snake gameplay
- Real-time score update
- Smooth keyboard controls
- Simple and clean UI
- Fully browser-based (no installation required)

---

## 🕹️ Controls

| Key | Action |
|----|-------|
| ⬆️ Arrow Up | Move Up |
| ⬇️ Arrow Down | Move Down |
| ⬅️ Arrow Left | Move Left |
| ➡️ Arrow Right | Move Right |

---

## 🛠️ Tech Stack

- **HTML5** – Game structure  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Game logic
